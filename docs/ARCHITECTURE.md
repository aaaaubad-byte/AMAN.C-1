# البنية المستهدفة

## مبادئ
- تطبيقان منفصلان: العميل والإدارة.
- الحفاظ على تقنية المصدر الحالية ما دامت مناسبة؛ لا فرض إطار عمل جديد لمجرد الحداثة.
- طبقة مشتركة صغيرة للخدمات والأدوات التي ثبت أنها مشتركة فعلاً.
- عدم ربط تشغيل AMAN.C-1 بمسارات أو ملفات خارج المستودع.
- لا نسخ متكررة من الملفات ولا تقسيم مفرط.

هذا هيكل تنظيمي مستهدف وليس أمراً بإنشاء كل ملف أو مجلد فارغ. تنشأ الملفات عند نقل مسؤوليات حقيقية وبعد فحص المصدر. تبقى ملفات PWA الخاصة بالعميل والإدارة مستقلة إذا تطلب تشغيلهما ذلك.

## حدود المسؤوليات
- apps/customer: شاشة العميل وربطها بخدمات العميل.
- apps/admin: شاشة الإدارة وربطها بخدمات الإدارة.
- shared/services: الاتصال والخدمات المشتركة والعقود فقط.
- shared/components: مكونات واجهة مشتركة ثبت تكرارها.
- shared/utils: أدوات عامة صغيرة غير مرتبطة بواجهة محددة.
- shared/styles: قواعد مشتركة حقيقية، مع إبقاء الأنماط الخاصة بكل تطبيق في ملفه.
- supabase/migrations: ترحيلات جديدة فقط، لا نسخ معدلة من ترحيلات مطبقة.
- tests: اختبارات الوظائف والصلاحيات والواجهات بحسب ما يتم نقله.
- scripts: أدوات تحقق أو نسخ احتياطي أو مراجعة لها استخدام فعلي.

## قرار التقنية
المصدر مشروع HTML/CSS/JavaScript؛ لا يتم فرض React أو Vite أو إعادة كتابة شاملة قبل إثبات الحاجة بمقارنة عملية موثقة.
