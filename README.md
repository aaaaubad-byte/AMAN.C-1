# AMAN.C-1

نسخة مستقلة ومنظمة من مشروع AMAN.C، هدفها المحافظة على وظائف المنتج وقواعده وواجهاته مع تحسين بنية الملفات والصيانة. ليست إعادة تصميم للمنتج.

## التطبيقات
- العميل: `apps/customer/`
- الإدارة: `apps/admin/`
- الخدمات والمكونات والأنماط المشتركة: `shared/`
- الأصول: `assets/`

## التشغيل المحلي
- معاينة المحاكاة المحلية: `npm run preview`
- معاينة بلا محاكاة: `node scripts/local-preview.mjs --no-simulation`
- فحص الملفات والمسارات وJavaScript وPWA: `npm run validate`
- الاختبارات: `npm test`
- اختبارات المتصفح تتطلب Playwright وChromium في بيئة التطوير.

المحاكاة محلية فقط ولا تتصل بقاعدة البيانات أو شركات الاتصالات. صفحات المنتج لا تحقن المحاكاة.

## المراجع
- `docs/PRODUCT.md`: قواعد المنتج.
- `docs/ARCHITECTURE.md`: البنية ومسؤوليات الملفات.
- `docs/DATABASE.md`: حالة Supabase وقواعد التعامل معها.
- `docs/DECISIONS.md`: قرارات المالك.
- `docs/WORK_RULES.md`: قواعد العمل.
- `docs/MIGRATION_MAP.md`: نقل الملفات ومصيرها.
- `docs/RESUME.md`: نقطة الاستئناف.
- `docs/HISTORY.md`: خلاصة الوثائق التاريخية.
- `docs/SCREEN_MAP_BASELINE.md`: خريطة الشاشات الأصلية.

## قيود
- يبقى مستودع AMAN.C الأصلي دون تعديل.
- لا قاعدة بيانات بديلة ولا تغييرات على Supabase الحية دون موافقة صريحة.
- لا نشر إنتاجي أثناء التطوير.
- لا تحفظ أسراراً أو مفاتيح خدمة خاصة داخل المستودع.
