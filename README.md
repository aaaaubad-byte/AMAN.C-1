# AMAN.C-1

المستودع المستقل لمواصلة تطوير مشروع أمان انطلاقاً من المستودع المصدر [AMAN.C](https://github.com/aaaaubad-byte/AMAN.C).

## الحالة
إغلاق متطلبات ما قبل النقل. لم يبدأ نقل الشاشات أو منطق التشغيل بعد. يبدأ النقل بعد حسم خصوصية المستودع وإكمال بوابات الجاهزية.

## مبادئ لا تتغير دون موافقة
- يبقى المستودع المصدر AMAN.C مستقلاً دون تعديل أو حذف أو تغيير إعدادات النشر.
- لا نشر ولا معاينات منشورة من AMAN.C-1 أثناء التأسيس والتطوير.
- قاعدة البيانات الحالية هي القاعدة المعتمدة؛ لا تعديل حيّاً ولا تطبيق ترحيلات دون مراجعة وموافقة صريحة.
- المحافظة على واجهات العميل والإدارة الحالية وسلوكها؛ لا إعادة تصميم.
- لا نقل ملفات عشوائياً ولا إضافة ملفات كثيرة أو نسخ بديلة متضاربة.
- لا أسرار أو مفاتيح خاصة أو كلمات مرور في المستودع.
