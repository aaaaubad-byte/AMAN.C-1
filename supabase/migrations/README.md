# ترحيلات Supabase

يستخدم AMAN.C-1 مشروع Supabase الحالي نفسه. سجل الترحيلات الحية وحالتها موثق في `docs/DATABASE.md`.

- لا تنسخ أو تطبق الترحيل القديم `20261101000100_initial_schema.sql`؛ لا يطابق المخطط الحي.
- أي تغيير مستقبلي يضاف كترحيل جديد متسلسل؛ لا تعدل ترحيلاً سبق تطبيقه.
- قبل أي تطبيق: مراجعة المخطط والأثر، نسخة احتياطية قابلة للاستعادة، خطة استعادة، وموافقة صريحة من المالك.
- لا تحفظ مفاتيح خدمة أو أسراراً في Git.
