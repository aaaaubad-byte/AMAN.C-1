# تشغيل بيئة AMAN.C التجريبية

هذه البيئة تحاكي خدمات العميل والإدارة محليًا في المتصفح فقط. لا تتصل بـ Supabase أو أي خادم أو قاعدة بيانات إنتاج.

## التشغيل
1. شغّل خادم ملفات ثابت من جذر المشروع، مثل: `python3 -m http.server 8080`.
2. افتح العميل: `http://localhost:8080/apps/customer/?demo=1`.
3. افتح الإدارة في تبويب آخر: `http://localhost:8080/apps/apps/admin/?demo=1`.
4. استخدم الحسابات:
   - المدير: `admin@aman.demo` وكلمة المرور `1234`.
   - العميل: `customer@aman.demo` وكلمة المرور `1234`.
5. البيانات مشتركة بين التبويبين على المتصفح نفسه وتبقى بعد تحديث الصفحة.
6. لإعادة التجربة إلى البداية استخدم زر «إعادة ضبط التجربة» في الشريط أعلى الصفحة.

## ملاحظات
- الوضع التجريبي لا يعمل إلا عند إضافة `?demo=1` إلى الرابط.
- البيانات محلية في `localStorage` ولا تنتقل إلى جهاز آخر.
- هذا ليس نظام مصادقة أو صلاحيات آمنًا؛ لا تستخدم بيانات حقيقية.
- لا تبدأ الحماية فعليًا ولا يتم الاتصال بشركات الاتصالات أو الدفع.
- لا تُحمّل هذا الملف في الإنتاج. أضيفت مراجعته كملف اختياري في HTML فقط؛ لا يُحمّل إلا عند وضع Demo.
